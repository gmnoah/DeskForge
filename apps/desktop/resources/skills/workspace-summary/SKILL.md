# 工作区总结

只阅读用户已经授权的工作区，给出能核对的现状说明。

## 范围

- 授权根就是当前工作区。不要把 `/`、家目录或磁盘上的其他位置当作工作区。
- 先用文件列表和搜索了解结构，再读取 README、清单文件和入口代码。
- 没有读取到的内容写成未确认，不要补全猜测。

## 输出

1. 工作区是做什么的。
2. 主要目录和入口。
3. 已看到的构建、测试或运行方式。
4. 还没读到、因此不能下结论的部分。
