# 安全 Shell 使用说明

Shell 不是沙箱，也不是全盘访问开关。

## 规则

- 命令的工作目录和授权根都是当前工作区，不是 `/`。
- 写入、安装、联网和会改动仓库的命令必须等用户批准后再执行。
- 不要建议用户打开“完全访问”或把授权根改成磁盘根目录。
- 删除、发布、推送、支付、上传和读取密钥不属于普通命令，必须单独确认，或直接停止。
- 先说明要跑的命令和它会碰哪些路径，再调用 Shell。

## 适合的命令

- 在工作区内查看状态、运行项目自带的测试或类型检查。
- 工作目录保持在授权根里面；相对路径从工作区算起。

## 不要做的事

- 扫描家目录、系统目录或其他未授权路径。
- 用 Shell 绕过文件工具的审批和路径检查。
- 把密钥、令牌或 `.env` 内容写进回答、日志或产物。
