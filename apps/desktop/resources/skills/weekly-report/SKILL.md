# 周报 / 日报整理

把散落在工作区里的工作记录整理成一份可以直接发给上级或同事的中文周报（或日报）。

## 范围

- 只读取当前工作区和任务附件。不要扫描桌面、家目录或其他文件夹，不联网。
- 先问清时间范围（默认本周一至今天）和读者（上级 / 团队 / 自己）；用户已说明时不要重复询问。

## 工作流

1. 用 `file_find` 查找可能的素材，例如 `*日报*`、`*周报*`、`*todo*`、`*.md`、`*.txt`，再用 `file_search` 按日期（如 `2026-10-`、`10月`）缩小范围。
2. 用 `file_read` 读取命中的文件；附件通过 `attachment_open` 打开。记录每条事实的来源文件。
3. 归并同类事项，按“已完成 / 进行中 / 风险与求助 / 下周计划”分组。数字、日期和人名必须来自素材，不要编造进度百分比。
4. 素材不足的部分写成「待补充」，并列出需要用户确认的问题。
5. 用户要求保存时，用 `file_write` 写入工作区，例如 `周报/2026-W41.md`；已有同名文件先读取并带上 `expectedSha256`。

## 输出格式

```markdown
# 周报（10月5日—10月9日）

## 本周完成
- 事项：结果（来源：日报/10-06.md）

## 进行中
- 事项：当前进度、预计完成时间

## 风险与需要的支持
- 问题、影响、希望谁提供什么帮助

## 下周计划
- 事项（优先级）
```

日报使用同样结构，标题改为日期，内容控制在 10 行以内。

## 完成标准

- 每条“已完成”都能追溯到素材文件。
- 没有出现素材之外的数字或承诺。
- 待补充事项单独列出。
