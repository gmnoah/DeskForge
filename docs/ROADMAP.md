# DeskForge 路线图

DeskForge 是本地优先的 macOS 桌面工作 Agent。这份路线图只列出近期要做的事，以及明确暂缓的事。每个里程碑完成后，会在 PR 和这里同时更新状态。

> DeskForge 是独立项目，不是 WorkBuddy，也不是腾讯的产品。

## M1 可用性打底 ✅ 已完成

状态：已在 PR #2 合并。

目标：第一次打开就能连上国产模型，出错时用户知道该怎么办。

- **CI**：GitHub Actions 在 push 和 pull request 时执行安装、typecheck 和测试（Ubuntu 已启用；macOS 矩阵需要有 workflow 权限的维护者推送）。
- **国产模型兼容**：按 DeepSeek、Kimi、通义（DashScope compatible-mode）的官方文档，核对流式输出与工具调用，并处理以下差异：
  - `reasoning_content` 的回传
  - 思考模式下 `tool_choice` 的限制
  - 并行工具调用
  - usage 字段的位置
  - 非标准 finish_reason
  - 固定采样参数
  - 已下线的模型 ID
  
  全部用夹具 / mock 测试覆盖，不依赖真实 Key。
- **测试连接**：引导页、添加模型弹窗和模型列表都有「测试连接」按钮。它发一个极小的请求，并给出明确的中文结果：Key 无效、地址错误、模型不存在、余额不足、限速、网络不通或超时。错误分类有单元测试。
- **中文报错与 token 用量**：对话失败时显示中文原因和处理建议，原始信息脱敏后放进「技术信息」；服务商返回 usage 时，按会话累计显示 token 用量。
- **文档**：刷新中文 README（快速开始、预设地址、白名单与审批、项目结构），新增本路线图和 CONTRIBUTING。

## M2 工作区工具与审批体验 ✅ 已完成

状态：已在 PR #3 合并。

目标：在工作区里找东西、改东西，都更快、更放心。

- ✅ **文件搜索 / 内容检索**：新增 `file_find`（文件名 / glob），重写 `file_search`（字面量 / 正则 / 大小写 / glob 过滤）。遵守 `.gitignore`，不跟随符号链接，跳过二进制和超大文件；结果数、扫描量和耗时都有上限，触顶时明确告知。只读工具，自动执行。
- ✅ **编辑前 diff 预览的审批卡片**：写入、编辑、提交草稿、删除前，审批卡片展示统一 diff（可切换并排），新建文件全部为新增行，超长时截断并注明。敏感配置只显示行数。变更产物也改用同一个 diff 生成器。
- ✅ **「本会话总是允许此类操作」**：按「同一工具 + 同一风险等级」放行；Shell 按命令前缀放行，且只接受简单命令。高风险、删除、外部发送和凭据相关操作永不自动批准。规则可在工作详情和「隐私与记录」中查看、撤销，应用重启后失效。自动批准照常写入审计日志，并记录命中的规则。删除类命令指向工作区外时直接拒绝。
- ✅ **审计日志查看与导出**：活动记录支持按工作、类别、结果、时间和关键字筛选，显示哈希链校验状态（内容重算 + 链接连续性），并通过保存对话框导出为 JSON / CSV / Markdown。
- 尚未做：分页加载（目前单次最多 500 条、导出最多 5000 条）；diff 卡片里「展开全文」（目前截断到 400 行）。

## M3 Skills 与 MCP ✅ 已完成

状态：已在 PR #4 合并。

目标：让能力扩展不需要改代码。

- ✅ **在设置里配置 MCP server**：「设置 → MCP 连接」可以添加、编辑、删除、启停 Server。支持 stdio（命令、参数、环境变量、工作目录）和 Streamable HTTP（URL、Header、Bearer / 自定义 Header / OAuth，可选旧版 SSE 兼容）。「测试连接」会列出发现的工具，每个工具可以单独停用。环境变量和 Header 可勾选「加密保存」，密钥值只以 `safeStorage` 密文保存，不进配置、界面和日志；名称像密钥却没勾选时拒绝保存。stdio 工作目录默认是每个 Server 独立的空目录，也可以选当前工作区或通过对话框指定文件夹。MCP 工具调用每次都要审批，不能被会话规则放行。
- ✅ **导入 Skill**：可以从本地文件夹或公开的 HTTPS Git 仓库（浅克隆，可选分支和子目录）导入。安装前预览文件清单、脚本、权限声明和提醒，确认时重新校验指纹；导入不执行任何脚本，拒绝软链接和越界子目录。支持更新（按记录的来源重新导入，Git 来源记录 commit）、启停和移除。
- ✅ **更多中文示例 Skill**：周报 / 日报整理、会议纪要、合同 / 文档要点、表格数据汇总、代码仓库速览，均只作用于工作区、不联网。
- 尚未做：私有 Git 仓库（需要登录）的导入；MCP 的 resources / prompts（目前只接入 tools）；按 Server 的调用次数与耗时统计。

## M4 会话与本地知识 ✅ 已完成（PR 审阅中）

目标：之前的工作能找得回来，工作区里的文档能被引用。

- ✅ **会话搜索**：侧栏搜索框同时检索会话标题和用户 / 助手消息正文（SQLite FTS5 + `trigram` 分词，中文无需分词器；两个字的中文词如「周报」自动回退到 LIKE）。结果显示命中片段，可按当前工作区过滤；系统消息和子 Agent 会话不参与检索。旧数据库启动时自动回填索引。
- ✅ **重命名 / 删除 / 导出**：会话标题栏可重命名（同步到搜索索引并写入审计）、删除（二次确认），以及通过保存对话框导出 Markdown。导出包含元信息、计划步骤、对话、工具调用摘要表、审批记录（结果与范围）、引用来源、产物和验证；模型 Key、MCP 密钥、向量接口 Key 等已知密钥按原值替换为 `[REDACTED]`，另外按形态识别 `sk-…`、GitHub / AWS / Slack 令牌、JWT、私钥块、URL 中的密码和 `password=` 等。
- ✅ **工作区本地知识索引**：「设置 → 本地知识库」为每个工作区建立、增量更新、完全重建或清除索引。索引是应用数据目录下每个工作区一个 SQLite 文件（不写入工作区），文件按行切块后写入 FTS5（trigram）。沿用 M2 搜索的约束：遵守 `.gitignore`、不跟随符号链接（读取前再次校验真实路径）、跳过二进制和超过 1 MB 的文本、扫描量和耗时有上限；另外永不索引 `.env`、私钥、`.npmrc` 等敏感文件。支持 Markdown / 纯文本 / 常见代码与配置文件 / `.docx`（内置轻量解析）。增量更新先比较大小和修改时间，再比较 SHA-256，只重切有变化的文件，并移除已删除或新被忽略的文件。
- ✅ **`knowledge_search` 工具**：只读、无需审批，Agent 默认可用。返回按相关度排序的片段，附 `路径:起始行-结束行` 引用；支持路径前缀过滤；多词无全量命中时回退为按命中词数排序。索引未建立时提示用户去设置中建立。
- ✅ **可选向量检索**：「设置 → 向量检索」可配置 OpenAI 兼容的 Embeddings 接口（预设：通义 DashScope text-embedding-v4 / v3、OpenAI text-embedding-3-small，或自定义）。默认关闭；启用前必须确认「文档片段和检索词会发送到 xx」，每次发送都写入审计日志；Key 用 `safeStorage` 加密，只在主进程使用。向量以 Float32 BLOB 存在同一个 SQLite 中，暴力余弦检索，与 FTS 结果用 RRF 融合；接口出错时自动回退为关键词检索。
- 尚未做：PDF 文本提取（目前跳过 PDF）；超大工作区的后台索引与进度条（目前在主进程中顺序执行，单个工作区上限 5000 个文件）；向量的 ANN 索引（P0 规模下暴力检索足够）；跨会话「同一行」以外的组合检索（多个词需出现在同一条消息或标题中）。

## 暂缓

以下事项已经明确暂缓，不在 M1 至 M4 的范围内：

- 签名、公证的 macOS 安装包
- 在真机上验证 Keychain 的各种边界情况
- API key 代理（把模型密钥从 agent worker 移回主进程，由主进程代理请求）
- Chrome 扩展与本机消息宿主
- 飞书、企业微信、钉钉等 IM 接入，无界面服务端，Windows 版本
