# DeskForge 路线图

DeskForge 是本地优先的 macOS 桌面工作 Agent。这份路线图只列出近期要做的事，以及明确暂缓的事。每个里程碑完成后，会在 PR 和这里同时更新状态。

> DeskForge 是独立项目，不是 WorkBuddy，也不是腾讯的产品。

## M1 可用性打底

目标：第一次打开就能连上国产模型，出错时用户知道该怎么办。

- **CI**：GitHub Actions 在 push 和 pull request 时，于 Ubuntu 与 macOS 上执行安装、typecheck 和测试。
- **国产模型兼容**：按 DeepSeek、Kimi、通义（DashScope compatible-mode）的官方文档，核对流式输出与工具调用，并处理以下差异：
  - `reasoning_content` 的回传
  - 思考模式下 `tool_choice` 的限制
  - 并行工具调用
  - usage 字段的位置
  - 非标准 finish_reason
  - 固定采样参数
  - 已下线的模型 ID
  
  全部用夹具 / mock 测试覆盖，不依赖真实 Key。
- **测试连接**：引导页、添加模型弹窗和模型列表都有「测试连接」按钮。它发一个极小的请求，并给出明确的中文结果：Key 无效、地址错误、模型不存在、余额不足、限速、网络不通或超时。错误分类有单元测试。
- **中文报错与 token 用量**：对话失败时显示中文原因和处理建议，原始信息脱敏后放进「技术信息」；服务商返回 usage 时，按会话累计显示 token 用量。
- **文档**：刷新中文 README（快速开始、预设地址、白名单与审批、项目结构），新增本路线图和 CONTRIBUTING。

## M2 工作区工具与审批体验

目标：在工作区里找东西、改东西，都更快、更放心。

- **文件搜索 / 内容检索**：按文件名 glob，以及按内容检索（ripgrep 风格），结果只限定在工作区内，并对大目录做分页。
- **编辑前 diff 预览的审批卡片**：写入或编辑文件前，在审批卡片里展示统一 diff，可以展开全文，批准后才落盘。
- **「本会话总是允许此类操作」**：在现有的「仅这一次」「本任务内允许此工具」之外，新增按会话、按操作类型的放行。它仍然受工作区白名单约束，也可以随时撤销。
- **审计日志查看与导出**：活动记录支持按任务、工具、结果筛选，并导出为 JSON / CSV。导出时校验哈希链。

## M3 Skills 与 MCP

目标：让能力扩展不需要改代码。

- **在设置里配置 MCP server**：支持 stdio 与 HTTP（含 OAuth）两种连接方式，可以测试连接、查看工具列表、按工具启停。所有 MCP 工具同样走风险分级和审批。
- **导入 Skill**：可以从本地文件夹或 git 仓库导入。导入前预览清单与权限声明，并固定到具体版本或 commit。
- **更多中文示例 Skill**：例如周报整理、会议纪要、代码评审清单、数据表清洗，均附带中文说明和安全约束。

## M4 会话与本地知识

目标：之前的工作能找得回来，工作区里的文档能被引用。

- **会话管理**：会话搜索、重命名，导出为 Markdown（含引用来源与工具记录摘要）。
- **工作区文档本地索引**：
  - 第一步：用 SQLite FTS5 做全文索引，增量更新，只索引白名单工作区。
  - 可选：接入 OpenAI 兼容的 embeddings 接口（可以复用已配置的国产模型服务），做语义检索。默认关闭，开启前明确提示哪些内容会发往服务商。

## 暂缓

以下事项已经明确暂缓，不在 M1 至 M4 的范围内：

- 签名、公证的 macOS 安装包
- 在真机上验证 Keychain 的各种边界情况
- API key 代理（把模型密钥从 agent worker 移回主进程，由主进程代理请求）
- Chrome 扩展与本机消息宿主
- 飞书、企业微信、钉钉等 IM 接入，无界面服务端，Windows 版本
