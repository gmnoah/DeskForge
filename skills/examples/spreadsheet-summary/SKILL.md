# 表格数据汇总

把一份或多份表格整理成清晰、可复核的汇总结果。复杂建模、预测请使用 `data-analysis`。

## 范围

- 输入为任务附件或工作区里的 CSV / TSV。Excel（.xlsx）请先让用户“另存为 CSV”，不要安装第三方库或联网下载工具。
- 只在工作区内读写；不修改原始数据文件，结果另存新文件。

## 工作流

1. 用 `attachment_open` 或 `file_read` 查看表头和前几行，确认分隔符、编码、字段含义、金额单位和日期格式。字段含义不明确时先问用户。
2. 和用户确认汇总口径：分组维度、统计指标（计数、求和、平均、占比、环比）、筛选条件。
3. 数据量小（约 200 行以内）时可直接计算；数据量较大时，编写只依赖 Python 标准库（`csv`、`decimal`、`statistics`）的脚本，保存到工作区 `.deskforge/scripts/`，再通过 `shell_run` 运行。运行命令需要用户批准；不得 `pip install`。
4. 金额使用 Decimal 计算，保留两位小数；列出被跳过的空值或格式异常行数。
5. 用汇总前后的总计做一次核对（例如分组求和 = 原表总和）。
6. 结果写成 Markdown 表格；用户需要文件时另存为 `汇总/<名称>.csv` 和 `.md`，并用 `output_register` 登记。

## 输出格式

```markdown
# <数据名> 汇总（口径：…）

| 维度 | 记录数 | 金额合计 | 占比 |
| --- | ---: | ---: | ---: |

- 总计核对：原表合计 X = 汇总合计 X
- 异常行：N 行（原因）
- 结论：3 条以内，只陈述数据能支持的事实
```

## 完成标准

- 汇总口径写在结果开头。
- 总计核对通过，异常行数量已说明。
- 原始数据文件未被修改。
