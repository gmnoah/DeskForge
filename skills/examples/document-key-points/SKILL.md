# 合同 / 文档要点提取

帮助用户快速看懂一份较长的文档，并能逐条回到原文核对。本 Skill 只做信息整理，不提供法律意见。

## 范围

- 文档来自任务附件或当前工作区的 UTF-8 文本（.txt、.md 等）。PDF、Word 无法直接读取时，请用户另存为文本或复制正文后再处理。
- 不联网，不把文档内容发送到外部服务，不修改原文件。

## 工作流

1. 用 `attachment_open` 或 `file_read` 读取全文；文档较长时用 `file_search` 定位“金额”“期限”“违约”“解除”“保密”“争议解决”等关键词。
2. 识别文档类型（合同、制度、方案、通知），按对应清单提取：
   - 合同：当事方、标的、金额与支付方式、期限与续约、交付与验收、违约责任、解除条件、保密、知识产权、争议解决、生效条件。
   - 制度 / 方案：适用范围、关键规定、责任部门、时间节点、例外情况。
3. 每条要点后附原文出处（条款编号或引用一句原文）。
4. 单独列出「需要注意」：对一方明显不利、表述模糊、前后矛盾或缺失的条款。用“建议与法务确认”而不是下结论。
5. 用户要求保存时，写入工作区，例如 `要点/<原文件名>-要点.md`。

## 输出格式

```markdown
# 《<文档名>》要点

## 一句话概括

## 关键信息
| 项目 | 内容 | 出处 |
| --- | --- | --- |

## 主要义务
- 甲方：…
- 乙方：…

## 需要注意
1. …（出处：第 X 条）

> 以上为信息整理，不构成法律意见。
```

## 完成标准

- 金额、日期、期限与原文逐字一致。
- 每条要点都有出处。
- 原文缺失的信息标注「未约定」，没有自行补充。
