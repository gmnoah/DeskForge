# DeskForge 独立实现起点

这是未来完整功能版本的前两批代码：任务与一次性审批内核、工作区文件适配器。未接入当前 Electron 应用。原生 ES modules 和 Node 标准库，无第三方运行依赖、无旧业务模块导入。

```sh
cd independent
npm test
npm run demo
npm run demo:files
```

Node >=22.14；无需安装依赖。demo 处理内存文档；demo:files 使用自动清理的临时目录，展示检索→预览→批准写入→批准回滚，不访问用户工作区或模型。

## 已实现

任务：直接/计划模式、计划确认、确认方式、宿主风险注册、参数冻结、一次性票据、执行前校验、串行执行、取消信号、终态保护和不含参数的事件记录。

文件：授权/撤销、目录身份检查、拒绝越界/符号链接/多硬链接、1 MB UTF-8 文本读取、敏感文件拦截、带行号引用的字面搜索、写入预览、版本绑定、同目录临时文件替换、工作区外的私有版本备份，以及跨适配器重启的冲突检查回滚。真实文件写入和回滚仍需逐次批准。

搜索支持授权根及子目录的常见 .gitignore 规则（*、**、?、!、目录规则、锚定）。字符类和转义规则显式报错；未实现工作区外父目录的 ignore、Git 全部语义、正则搜索、ripgrep 后端。不能标记为旧搜索功能完全兼容。

## 限制与后续

命令、模型、会话数据库、崩溃/断电恢复、审批身份 IPC、桌面 UI、长期授权和审计哈希链尚未实现。备份包含原文，宿主必须提供权限 0700 的私有目录并管理保留/清除；此原型不加密备份。

Node 路径检查与 rename/unlink 之间仍可能受到恶意本地进程并发目录替换影响；O_NOFOLLOW 仅保护最终打开的文件，同步 I/O 与重复检查不构成 OS 沙箱。文件适配器注册 write 风险，在自动模式也要批准。恢复原文不保证恢复所有权、扩展属性、ACL 或原始时间戳。备份记录在替换前落盘，但 prepared 记录的崩溃恢复及断电可靠性仍需实现。

变更预览展示一个替换区间，最多 400 行，每行最多 4096 字符，不保证最小 diff。原始备份与预览完整文本上限为 1 MB。预览最多保存 100 份，可由宿主 discardPreview 清除；撤销授权后全部清除。

完整兼容范围见 ../docs/rebuild/ACCEPTANCE.md。下一批 B3：模型、会话格式与桌面入口，同时继续补齐搜索兼容和文件竞态保护。新目录暂时共处旧仓库；新模块完成不代表整套软件已独立。
